# 🌱 Stem

Ambient writing and inline text enhancement assistant for Android.

Instant on-device heuristics, local Ollama over Wi-Fi, and cloud LLMs—without popups, lock-in, or telemetry.

## Features

- **Ambient**: Trigger via native text selection menu (`ACTION_PROCESS_TEXT`), inline commands (e.g. `;;fix`), or snippet expansions.
- **Private**: 100% on-device rules by default. No telemetry or analytics.
- **Engines**: 40+ on-device heuristics, local Ollama (LAN), or BYO-key APIs (Gemini, Claude, OpenAI).
- **Presets**: Fix, Concise, Formal, Punchy, Friendly, Summarize, Bulletize, Expand, and Custom.
- **Visual Diff**: Inline token-level diff preview before replacing text.
